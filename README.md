# TodoMVC React

A TodoMVC application built with React and Vite.

## Features

- Add new todos
- Mark todos as completed
- Edit todos
- Delete todos
- Filter by All, Active, and Completed
- Toggle all todos
- Clear completed todos
- Display the number of active items left
- Save todos using localStorage
- URL hash routing for filters

## Technologies Used

- React
- JavaScript
- CSS
- Vite
- localStorage

## Run the Project

Install the dependencies:

npm install

Start the development server:

npm run dev

Then open the local URL shown in the terminal.
